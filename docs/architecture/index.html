3.2 真实成本数据路径

数据源：proj_facana.ads_fin_fact_day_storeloss_pp（门店日损益表）
口径：d1_pf_（业绩口径-地区版）为默认，另有 d2_（返利）、d4_（预算）、d1t_（同期）
处理：按门店按月汇总日数据，取最近 3 月均值
成本拆分：采购成本率 + 人工(工资+社保) + 租金物业 + 营销(商场费) + 物流(快递) + 折旧(装修) + 其他
降级：无损益数据的门店自动使用默认比例（COGS 45%、人工 10%、租金 5%...）
标记：StoreProfit.data_source = "real" | "default"

四、承压分配方法论

4.1 分配公式

目标缺口：G = Ptotal - ΣBi（老板总目标 - 各店基线汇总）
门店权重：Wi = α×历史利润归一化 + β×坪效归一化 + γ×商圈系数 + δ×面积归一化 + ε×增长趋势
承压额：Δi = G × Wi / ΣWi
分配目标：Ti = Bi + Δi
保底约束：Ti ≥ Bi × 80%（防止过度施压）
权重默认值：α=0.35, β=0.25, γ=0.20, δ=0.10, ε=0.10

4.2 权重因子

维度权重数据来源业务含义
历史利润35%月度指标聚合能力越强，承担越多
坪效水平25%销售额 / 面积高坪效 = 更大提升空间
商圈等级20%门店主数据A 级商圈承压上限更高
门店面积10%门店主数据大面积门店容量更大
增长趋势10%近 3 月同比上升期门店可多承担
