3.2 成本预估器（CostEstimator）

核心方法：from_store_loss_data(store_loss_df, targets, months=3)
数据源：ads_fin_fact_day_storeloss_pp 的 d1_pf_ 口径（业绩-地区版）
处理：按门店按月汇总日数据 → 取最近 3 月均值 → 构建成本结构
成本拆分：cogs_ratio + salary(工资+社保) + rent(残差估算) + marketing(商场费) + logistics(快递+B管理×0.3) + depreciation(装修费) + other
安全阀：cogs_ratio 限制在 [0.20, 0.80]，防止异常值
降级：无数据门店自动使用默认比例，标记 data_source="default"

3.3 利润计算器（ProfitCalculator）

字段说明来源
revenue收入（分配目标）AllocationAgent
cogs采购成本revenue × cogs_ratio
salary人工成本CostEstimator（真实）或默认 10%
rent租金CostEstimator（真实）或默认 5%
marketing营销费用CostEstimator（商场费）或默认 3%
logistics物流费用CostEstimator（快递）或默认 2%
data_source数据来源标记"real" | "default"
social_fee / mall_fee / ...明细扩展字段CostEstimator
